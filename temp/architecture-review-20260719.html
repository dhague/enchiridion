Problem — the typed-edge schema (six edge keys, the single-vs-list split between raw_source and the edges, the quoted-link format, the YAML-flow-list trap tested by test_tags_flow_list_not_mistaken_for_a_link) exists only as prose in SKILL.md and as regression assertions in test_links_frontmatter.py. frontmatter.py is a shallow generic key/value module — its interface is nearly as complex as its implementation (get one value, set one value) — so every edge-shape rule is pushed onto the LLM ingestion agent constructing the quoted-link string by hand, un-tested, every time it writes a relationship.

Solution — add a small module that knows the wiki's edge vocabulary and exposes add_edge(text, edge_type, title, rel_path), set_raw_source(text, title, rel_path), and validation of edge-type names, built on top of the existing frontmatter.get/set. The quoting and single-vs-list mechanics move behind this interface once, instead of living in agent-generated strings.

Wins
  • leverage: one interface, every edge write
  • locality: edge-format bugs concentrate in one module
  • deletion test passes: schema logic reappears at every agent call site today
  • 235-line frontmatter test file shrinks to scalar get/set only; edge-shape tests move onto the deep module's own surface

Problem — links.py apply_move hand-rolls its own "read every *.md under the vault root" walk. SKILL.md references a build_index.py that will need the same walk, but it doesn't exist yet — today there is exactly one caller.

Solution — not yet. One adapter is a hypothetical seam, not a real one — extracting vault.load_pages() now would be guessing at an interface before a second caller proves what it needs to look like.

Flagged only so it isn't re-discovered from scratch: when build_index.py (or a linter) lands and needs the same walk, that's the moment to pull load_pages() into vault.py — not before.

Top recommendation

Give the typed-edge schema a module

The deletion test passes cleanly: delete the proposed module and the edge-format knowledge doesn't vanish, it reappears — inside every ingestion call that has to hand-build a quoted markdown link with the right key. That knowledge is currently untestable because it lives in agent-generated text, not in the deterministic script layer the rest of this codebase is built on.
